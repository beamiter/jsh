# Execution, completion, persistence, and streaming upgrade

Date: 2026-10-26

Baseline: `1f0d5dab6501448870c9a884b3d2d4f7de10138d`

This change improves four core paths while preserving the on-disk bookmark and
directory-frecency formats and the Agent protocol. CI follow-up also updates the
TLS/YAML dependency chain and repairs platform/test prerequisites.

## Behavior changes

### Shell execution and output

Redirection failures now stop the affected command. This applies to builtins,
functions, typed functions and bindings, compounds, and external programs.
Assignment-only redirects also run, ambiguous file targets are rejected, and
descriptor restoration handles originally closed descriptors and collisions
with private descriptors in outer execution scopes. Nested `exec` redirects
cannot destroy an outer scope's saved descriptors.

`noclobber` protects existing regular files, with `>|` and `N>|` for an explicit
overwrite. Here-documents preserve empty lines, carriage returns, and the final
newline; their private backing files are unlinked before writing. Structured
output uses a writer bound to the active destination and flushes before the
redirection scope ends. Stream rows are delivered promptly, and buffered data
from a failed write cannot escape into a subsequent command's output.

`exec` now replaces the process, preserving its PID. It supports `-a`, `-c`,
`-l`, `--`, the usual 126/127 failure statuses, `execfail`, and persistent
redirection-only invocation. Assignment prefixes are exported to the replacement
even inside a function-local scope. Failed replacements restore signal handlers
and temporary assignment state when the shell is allowed to continue.

Unhandled `set -e` failures unwind nested loops and compounds at the first
failure. Conditional exemptions survive direct compounds, tested functions keep
conditional suppression, and `eval`/source preserve exit and return control.
Loop-condition `break`/`continue` belongs to its own loop. Completion and EXIT
traps save and restore the new transient execution state.

### Interactive completion

Path insertion preserves supported UTF-8 filenames containing shell metacharacters
in unquoted, single-quoted, double-quoted, and mixed path contexts. Directory
symlinks, assignment values, and escaped tilde prefixes are covered. Non-UTF-8
names and hidden terminal controls are omitted instead of being changed silently.

Directory scanning examines at most 65,536 entries and returns at most 4,096
candidates. Description reads are limited to 64 candidates per matching pass;
directory item counts stop after 257 entries. Programmable completion groups
quoted words, supports function `return`, and restores completion arrays,
positionals, status, and control-flow flags.

### Shared state

Bookmark and directory-frecency writes acquire a bounded-wait lock, reload the
latest file, apply the requested operation, and save atomically. This preserves
concurrent additions and cumulative visits and prevents a stale snapshot from
reviving a deletion. In-memory snapshots change only after a successful save.
Explicit add/remove operations report write failures, and bookmark whitespace
is retained. Lock sidecars must be safe, owned, single-link regular files.

### Structured streams and numeric correctness

For Stream input, field-form `where`, `chunks`, and `window` consume rows on
demand. Chunk and window iterators retain O(size) input rows internally;
`take 0` does not pull the source. `any`/`all` stop at the deciding row or predicate
error, and `is-empty` inspects at most two stream items. JSON byte input still
decodes before row processing; already-materialized Values input keeps eager
output. Sizes and strides are checked before iteration without oversized initial
allocations or unsigned overflow.

Integer sums accumulate in i128 and require an i64 final result; encountering
a float switches to f64. `min`/`max` preserve selected integer values. Mixed
integer/float comparisons do not lose integer precision above 2^53. Sorting has
a transitive category order and preserves equal-value input order in either
direction. Field-form equality remains textual, while relational predicates use
the shared numeric comparison rules.

The PTY check completed a filename containing literal `$(touch executed)` and
verified that accepting the completion did not execute it. The stream-output
regression uses a producer/consumer handshake: the consumer must receive the
first row before acknowledging it so that the producer can emit the next row.
It does not infer prompt delivery from a large finite input.

New integration suites cover redirection/exec semantics, compound termination,
completion paths, persistence failures, stream demand, numeric ordering, and
timely stream output. Many shell-semantic cases compare with Bash. Tests for
private descriptor isolation assert jsh's own invariant directly.

Reproduce the main gates on a normal development machine:

```sh
cargo fmt --all -- --check
cargo test --locked --all-features --no-fail-fast
cargo test --locked --no-default-features --no-fail-fast
cargo clippy --locked --all-targets --all-features -- -D warnings
cargo clippy --locked --all-targets --no-default-features -- -D warnings
cargo doc --locked --all-features --no-deps
cargo build --release --locked --all-features
cargo bench --locked --all-features \
  --bench bench_core --bench bench_value \
  --bench bench_completion --bench bench_streaming -- --test
```

Run the two feature configurations sequentially, or give them separate target
directories. Their subprocess tests share `target/debug/jsh`, so concurrent
builds in one target directory can invalidate each other's feature assumptions.

This environment ran these commands offline after fetching locked dependencies.
The complete test runs needed ordinary process sessions and local loopback
sockets. Because the container runs as root, DAC override/read-search capabilities
were dropped with `setpriv --bounding-set=-dac_override,-dac_read_search` so
unreadable-file tests exercise normal permission semantics. An initial sandboxed
benchmark command also selected libtest and hit the environment's existing
session-ID mismatch; the explicit four Criterion targets above all passed.
Existing ignored annotations were retained: isolated helper entries are invoked
by their owning tests, while live Docker/systemd probes remain excluded. macOS
was not exercised locally.

### CI follow-up

The first published revision exposed several failures in the hosted CI environment.
The installer job now installs minisign and ShellCheck explicitly. The helper's
kernel parent-death hook is compiled only on Linux/Android; other platforms keep
the existing process-group isolation, cancellation, timeout, and output-limit
cleanup. Both omissions already existed in the baseline.

A busy filesystem can legitimately exhaust the persistence lock's two-second
wait budget. Injecting 150 ms into each fsync reproduced that specific timeout
in the four-thread bookmark test. The test now retries only WouldBlock within a
bounded per-writer budget, immediately reports other errors, and verifies all
32 expected names. The production lock timeout and persistence protocol are
unchanged; the delayed-sync check completed successfully.

The advisory check also flagged the baseline's TLS packages and the unmaintained
unsafe-libyaml dependency under serde_yaml_ng. TLS is updated to rustls 0.23.46,
rustls-webpki 0.103.16, and webpki-roots 1.0.10. YAML moves to serde-saphyr 2 with
only serialization/deserialization enabled; optional include/property features
are disabled. The deny policy prevents the three old YAML crates from returning
and keeps an empty advisory ignore list.

Relevant upstream advisories: [TLS handshake](https://rustsec.org/advisories/RUSTSEC-2026-0285.html),

## Compatibility boundaries

- Advanced Bash behavior remains incomplete, including ordinary function ERR-trap
  inheritance and descriptor-moving syntax such as `N>&M-`. Unsupported descriptor
  moves now fail explicitly. DEBUG/RETURN traps remain accepted but unfired.
- Closure-form `where` and `each` still materialize input. `from-ndjson` still
  skips malformed lines. Average, product, and statistical formulas use floats.
- YAML retains ordered fields, ordinary `<<` keys, non-finite-number-to-null
  conversion, and parser resource budgets. Nesting is limited to 32 levels to
  protect a normal worker thread's stack. The new parser rejects some
  mixed-type keys with identical text, for example boolean `true` alongside
  string `'true'`, and does not support explicit `!!timestamp` tags. Duplicate
  field names after conversion are errors. YAML quoting in names derived from
  complex/tagged keys can differ from the previous serializer, and uncommon
  global tags follow the new parser's type inference. The completion readers
  return no candidates when parsing fails. Optional include/property expansion
  is disabled.
- Read-only bookmark/frecency views use the process snapshot until a successful
  update or reload. Already-running old versions do not honor the new locks.
- Atomic rename protects file replacement; an error syncing the parent directory
  may be reported after the replacement has happened. A failed write does not
  commit the in-memory snapshot early.
- Completion functions are trusted shell code with their normal side effects.
  Docker helpers inherit user configuration and can contact a configured remote
  daemon. Completion does not promise to enumerate non-UTF-8 filenames.
- The package version remains 0.2.0 with these changes under Unreleased. This
  source update does not create or sign a release archive.

# Probes whose jsh output deliberately or currently differs from bash.
# Format: NAME  reason
#
# Deliberate: jsh syntax that takes precedence over the bash reading.
x_let_typed_form_kept  `let NAME = EXPR` with a bare `=` is jsh's typed binding
x_brace_json_kept  a word that is a JSON object literal stays one word for structured pipelines
#
# Open differences.
y_exit_in_function_with_exit_trap  FUNCNAME is already unwound when `exit` in a function reaches the EXIT trap
y_nounset_array_element  an unset-variable error under `set -u` exits 1; bash -c exits 127
#
# Nondeterministic in bash itself: whole-second SECONDS depends on where
# the start time falls within its second.
seconds_advances  bash's own result varies between 1 and 2
